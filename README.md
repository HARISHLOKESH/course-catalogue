# Course Catalogue Website

A dynamic Course Catalogue Website built using Node.js, Express.js, EJS, and CSS.

## About the Project

SkillUp Academy is a simple course catalogue platform that allows users to explore available courses, search for courses, and view detailed course information.

## Features

- Home page displaying popular courses
- View all available courses
- Search courses by title
- Individual course details page
- About page
- Custom 404 error page
- Responsive and clean user interface

## Technologies Used

- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd course-catalogue
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm start
```

5. Open your browser:

```text
http://localhost:3000
```
